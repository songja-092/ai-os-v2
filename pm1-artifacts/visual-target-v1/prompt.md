Tool: `OpenAI built-in ImageGen`

## Brief

Create one implementation-ready 1600×1000 desktop dashboard for `AI OS V2`. Preserve the trusted information structure of the previously preferred V2 dashboard and workspace images while replacing the dark navy shell with a light cool gray-blue application shell.

Required navigation: `대시보드`, `프로젝트`, `자료 조사`, `스킬·기능`, `Docker`, `작업 기록`, `설정`.

Required content:

- quiet header with global search and `동기화됨`
- `빠른 실행`: `새 프로젝트`, `기존 프로젝트 등록`, `최근 작업 계속`
- compact scalable Project list with filters
- `PDF 도면 기호`, `동네 병원 웹`, `Oya`
- restrained `백그라운드 작업`
- separate `동기화 상태`
- collapsed `제작 흐름 보기`

Prohibited:

- `지금 할 일`
- dark navy background
- avatar, initials or team switcher
- expanded Core flow
- charts and fake metrics
- Reference gallery or Visual Companion UI
- purple/pink AI styling
- weak borders, tiny gray text or excessive prose
- repeated A/B/C alternatives

Implementation direction:

- Swiss-modern rational grid
- true light cool gray-blue background and white surfaces
- Inter-like typography
- muted cobalt primary and restrained teal status
- medium density, 8px spacing rhythm, modest radius
- shadcn-compatible Sidebar, Card, Table, Badge and Button anatomy
- subtle 150–250ms interaction cues only
