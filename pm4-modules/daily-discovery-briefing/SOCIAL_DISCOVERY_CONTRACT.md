# 소셜 자료 탐색 계약 v1

## 최근 30일·알고리즘 활용 규칙

- 사용자가 확정한 조사 기간은 `최근 30일`이다.
- 플랫폼 추천 알고리즘은 관련 채널과 원문을 발견하는 보조 수단으로만 쓴다.
- 플랫폼이 보여준 순서를 V2의 인기 순위로 그대로 사용하지 않는다.
- 관련 채널을 먼저 줄이고, 그 채널의 최근 30일 콘텐츠를 수집한다.
- 자동 선택하지 않고 사용자가 `채택·보류·폐기`를 결정한다.

사용자가 쉬운 말로 조사 주제를 입력한다.

1. V2가 원문 의미를 유지한 검색어·해시태그 후보를 만든다.
2. 수집기는 선택한 Instagram·Threads·YouTube·Reddit·GitHub에서 접근 가능한 공개 자료와 공개 반응 수치만 수집한다.
3. 분석기는 플랫폼별 결과 안에서 조회·좋아요·댓글·재게시 수치의 상대 순위를 계산한다.
4. V2는 요청과 연결되는 이유 또는 확인이 필요한 이유를 한 줄로 표시한다.
5. 사용자는 원문 링크를 열어 보고 `채택·보류·폐기` 중 하나를 선택한다.

## 인기 표시 규칙

- 기본 결과 수는 10개다.
- 조회수 50%, 좋아요 30%, 댓글 15%, 재게시·공유 5%를 기본 가중치로 사용한다.
- 공개되지 않은 수치는 0으로 만들지 않고 `확인 불가`로 표시한다.
- 사용할 수 있는 수치만으로 가중치를 다시 나눈다.
- Instagram과 Threads의 숫자를 한 순위에 바로 섞지 않는다.
- 인기 점수는 해당 수집 결과 안의 상대 비교일 뿐, 품질이나 채택을 의미하지 않는다.
- 수집기와 분석기는 자동으로 채택·폐기하지 않는다.

## 교체 가능한 연결 방식

- 현재: 로그인된 전용 Chrome을 이용하는 로컬 Adapter Pilot
- 후보: Meta 공식 API를 사용하는 MCP
- 유료 후보: 여러 소셜 플랫폼 검색 API를 사용하는 MCP
- 어느 방식을 사용해도 최종 출력은 같은 10개 결과 계약으로 변환한다.
- Adapter를 제거해도 사용자 판정과 저장된 Artifact는 보존한다.

## 개인정보 경계

- 비밀번호·인증번호·세션 Cookie를 Artifact에 저장하지 않는다.
- 홈 피드·DM·연락처·비공개 프로젝트 자료를 수집하지 않는다.
- 로그인이 만료되면 우회하지 않고 `로그인 필요`로 중단한다.
