# V2 초보자 용어집

실제 대화에서 필요한 용어만 골라 사용한다. 한 번에 모두 보여주지 않는다.

| 용어 | 한글 발음 | 쉬운 뜻 | V2에서 하는 역할 |
|---|---|---|---|
| OS | 오에스 | 여러 작업과 도구를 관리하는 바탕 시스템 | V2 전체의 정체성 |
| ERP | 이알피 | 회사의 고객·재고·회계 같은 업무를 묶어 관리하는 시스템 | V2가 만들 수 있는 자식 제품 중 하나 |
| Board | 보드 | 필요한 화면과 결과물을 올려 관리하는 판 | V2가 Skill과 Module을 다루는 작업판 |
| Skill | 스킬 | AI가 일을 수행하는 방법이나 도구 | 조사·디자인·검사·구현 방법 |
| Module | 모듈 | 장착·제거·재사용할 수 있는 실제 결과물 | 제작된 웹·기능·도구 |
| Section | 섹션 | 한 화면 안에서 역할이 나뉜 구역 | 요구사항 대화·Preview 같은 화면 영역 |
| Adapter | 어댑터 | 서로 다른 형식을 이어주는 변환 연결부 | 외부 Skill을 원본 수정 없이 V2에 연결 |
| Fixture | 픽스처 | 실제 제품 대신 시험에 쓰는 가짜 예시 | 안전한 기능·화면 검증 자료 |
| Registry | 레지스트리 | 사용 가능한 항목의 등록 목록 | 채택된 Skill·Module 목록 관리 |
| Manifest | 매니페스트 | 항목의 이름·권한·필요조건을 적은 설명표 | 연결 전 안전 조건 확인 |
| Recipe | 레시피 | 다시 만들 수 있도록 구성과 선택을 기록한 조리법 | 승인된 디자인·배치 재사용 |
| Visual Target | 비주얼 타깃 | 구현 전에 사용자가 승인한 목표 화면 | 디자인 정답 기준 |
| Core | 코어 | 상태·승인·증거·복구를 책임지는 중심부 | V2의 안전한 판단과 기록 담당 |
| Commit | 커밋 | 변경 내용을 이름 붙여 저장한 복구 지점 | PM 완료 상태 보존 |
| Tag | 태그 | 특정 Commit에 붙인 찾기 쉬운 이름표 | 완료 PM 복귀 지점 |
| Rollback | 롤백 | 문제가 생기기 전 상태로 돌아감 | 실패한 변경 취소 |
| Restore | 리스토어 | 저장해 둔 상태나 자료를 다시 복원함 | Version·배치·파일 복구 |
| UI | 유아이 | 사용자가 눈으로 보고 누르는 화면 | V2와 고객 제품 화면 |
| UX | 유엑스 | 사용자가 작업을 끝내는 전체 경험 | 초보자 흐름과 편의성 |
| API | 에이피아이 | 프로그램끼리 정해진 방식으로 대화하는 통로 | Core와 외부 도구 연결 |
| React | 리액트 | 화면을 Component 단위로 만드는 웹 도구 | 후속 V2 화면 구현 후보 |
| Vite | 비트 | 웹 개발 화면을 빠르게 실행·Build하는 도구 | React 개발환경 후보 |
| Playwright | 플레이라이트 | 실제 Browser에서 클릭과 화면을 자동 검사하는 도구 | 회귀오류와 상호작용 검증 |
