# Idea Archive

이 폴더는 AI OS V2의 현재 개발·마일스톤·로드맵과 분리된 장기 아이디어 보관소입니다.

## 격리 규칙

- 이 폴더의 문서는 V2의 채택된 기능, 공식 로드맵, Run 또는 마일스톤이 아닙니다.
- `wiki/`, `runs/`, `state/`, V2 Core와 자동으로 연결하지 않습니다.
- 이 폴더의 내용으로 새 Run, 구현, 패키지 설치, 마일스톤 변경을 시작하지 않습니다.
- 사용자가 해당 아이디어의 이름을 지정하고 “열어서 진행”을 명시적으로 요청할 때만 재개합니다.
- 재개하더라도 바로 구현하지 않고 현재 V2 상태와 분리된 새 작업 범위를 먼저 확인합니다.
