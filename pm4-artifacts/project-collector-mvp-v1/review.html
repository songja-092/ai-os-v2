전자명함 제작 자료

기능은 인터뷰에서 이미 확정했습니다. 사람들의 실제 사용 사례를 먼저 보고, 그 방향을 만들 수 있는 오픈소스를 나중에 연결합니다.

1. 확정된 기능

연락처 저장전화문자이메일카카오·SNS웹사이트QR 접속

2. 조사 순서

① 사람과 시장: Reddit·YouTube·Instagram·Threads에서 실제 사용법·불편·보이는 방식을 찾습니다.
② 제작 가능성: 정리된 방향에 맞는 GitHub 코드와 라이선스를 확인합니다. GitHub 저장소 자체가 디자인 시안은 아닙니다.

3. 만들 수 있는 방식 5개

Core 추천은 인터뷰와 근거를 바탕으로 한 제안이며 자동 선택이 아닙니다. 다른 후보도 삭제하지 않습니다.

Core 상태를 불러오는 중입니다.
