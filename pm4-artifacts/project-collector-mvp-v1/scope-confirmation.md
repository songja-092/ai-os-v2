# 전자명함 PM4 MVP 제작 범위 확인서

## 이렇게 이해했습니다

- 사회복지사용 간단형 전자명함 자료를 조사합니다.
- QR을 열면 사람 사진과 기관·회사 브랜드가 함께 보이는 명함 웹페이지가 나타납니다.
- 명함에서 연락처 저장, 전화, 문자, 이메일, 카카오톡 또는 SNS, 웹사이트 연결이 가능해야 합니다.
- 한국과 해외 사례를 함께 조사합니다.
- 무료·오픈소스로 실제 제작을 시도할 수 있는 자료만 구현 후보로 취급합니다.
- 필수 기능은 같고 시각 방향은 서로 다른 후보 5개를 보여줍니다.

## 그대로 유지합니다

- 현재 뉴스·도구 브리핑 Module은 별도로 보존합니다.
- 실제 개인정보는 조사 입력이나 외부 검색에 사용하지 않습니다.
- 사용자 선택 전에는 외부 도구 설치, Preview 제작, 제품 변경, 배포를 하지 않습니다.
- 후보를 수집했다는 이유만으로 자동 채택하지 않습니다.
- Reddit·YouTube·Instagram·Threads에서 실제 사용 사례·불편·표현 방식을 먼저 찾습니다.
- GitHub는 위 조사에서 정한 방향을 실제로 구현할 코드·기능·라이선스가 있는지 나중에 확인합니다.
- GitHub 저장소 목록을 디자인 시안 목록으로 사용하지 않습니다.

## 확인 방법

- 전자명함과 직접 관련된 후보만 표시되는지 확인합니다.
- 후보마다 원문 Link, 사용할 수 있는 기능, 선정 이유, 라이선스를 표시합니다.
- 중복 제거와 출처 하나의 실패가 다른 결과에 영향을 주지 않는지 검사합니다.
- 후보 5개가 기능은 같고 시각 방향은 서로 다른지 확인합니다.
- 사용자의 선택이 Core에 저장되고 새로 열어도 복원되는지 확인합니다.
- 중단하면 기존 프로젝트와 제품이 변경되지 않는지 확인합니다.

- 명세 기반 수집: 실행 허용
- 구현 허용: 아니오
