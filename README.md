# AI OS V2

AI OS V2는 비개발자가 자연어 요청부터 검증된 소프트웨어와 안전한 Git 복구까지 진행할 수 있도록 기존 개발 도구를 조립하는 프로젝트입니다.

현재는 M1~M7 MVP 마일스톤 중 `M1 — Run·Git 안전 기반`의 M1.1 범위를 독립 검증했고 M2 착수를 준비하는 단계입니다. 최신 공식 상태는 [wiki/CURRENT_STATE.md](./wiki/CURRENT_STATE.md), 마일스톤 PASS 기준은 [wiki/VERIFICATION.md](./wiki/VERIFICATION.md)를 따릅니다.

## Source of Record

GitHub의 이 저장소와 Git commit 이력이 공식 기록입니다.

- Obsidian: 사람이 Wiki를 읽고 편집하는 인터페이스
- GitHub: 공식 원본, 버전 이력, AI 공용 통로
- Archify: 특정 commit의 실제 구조를 시각화하는 파생 도구
