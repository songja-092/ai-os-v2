# 수집·분석

## 실제 목표

공사별 시작일과 종료일을 월 달력 위의 연속된 색상 막대로 보여 주고, 휴대전화에서 막대의 왼쪽 또는 오른쪽 끝을 터치해 날짜를 바꾸는 화면이다. 단순히 날짜 입력칸 두 개를 추가하는 것이 아니라 일정의 기간과 겹침을 한눈에 확인하고 직접 조정하는 것이 핵심이다.

## 가능 여부

가능하다. 다만 현재 대상 프로젝트에는 달력, 공사 일정 자료 구조, 편집 또는 저장 기능이 전혀 없다. 공식 기능으로는 구현 경로가 확인됐지만 이 프로젝트와 실기기에서 실행하지 않았으므로 현재 최대 상태는 `researched`다.

## 후보 1 — FullCalendar Standard 월 달력

- 무료 MIT Standard의 DayGrid로 여러 날짜에 걸친 공사 일정을 기간 막대로 표시한다.
- Interaction 기능의 `editable`, `eventDurationEditable`, `eventResizableFromStart`를 사용해 종료일뿐 아니라 시작일 쪽도 변경한다.
- 터치에서는 장기 누르기 후 조작하게 하고, Preview에서 대기 시간과 손잡이 크기를 모바일에 맞춘다.
- `eventResize`에서 시작일·종료일을 화면 상태에 반영하고 잘못된 순서나 저장 실패 시 `revert()`한다.
- 현재 Vite + TypeScript 앱에 프레임워크 전환 없이 붙일 수 있다.
- 한계: 전문 Gantt의 공정별 행은 포함하지 않는다. 일정이 많은 월과 작은 화면에서는 막대 가독성, `+more`, 세로 스크롤 충돌을 시험해야 한다.

## 최종 추천

`fullcalendar-standard-touch-range`를 추천한다. 요청에 필요한 월 달력 기간 막대와 터치 양끝 변경이 공식 Standard API 안에 있고, React 같은 새 프레임워크나 유료 Timeline을 도입할 이유가 없다. 다음 단계에서는 실제 제품을 바꾸기 전에 가짜 공사 일정 3개를 사용한 별도 Preview 한 개로 조작감을 확인한다.

## 포함 범위

- 한 달 보기와 이전 달·다음 달 이동
- 공사명, 시작일, 종료일, 구분 색상을 가진 가짜 일정 3개
- 여러 날짜에 걸친 기간 막대
- 마우스와 터치 장기 누르기로 시작일·종료일 변경
- 시작일이 종료일보다 늦어지는 변경 차단 또는 되돌리기
- 날짜 변경 후 화면에 즉시 반영되는 임시 상태
- 키보드·보조기술 사용자를 위한 일정 선택 후 시작일/종료일 입력 대체 수단

## 제외 범위

- 로그인, 사용자·권한 관리, 서버, 실시간 협업
- 데이터베이스, 클라우드 동기화, 알림, 외부 달력 연동
- 공정별 행을 가진 Gantt/Resource Timeline, 작업 의존선, 공정률, 인력·장비 배정
- 일정 생성·삭제, 반복 일정, 엑셀/PDF 내보내기
- 대상 병원 사이트의 기존 화면에 최종 통합하거나 배포하는 작업

## 모바일

390px와 430px에서 막대가 날짜 경계를 정확히 넘는지, 장기 누르기 후 양끝이 각각 움직이는지, 달력 세로 스크롤을 방해하지 않는지 확인해야 한다. 터치 손잡이는 최소 44×44 CSS px 수준의 조작 영역을 확보하고, 드래그만 강제하지 않도록 선택된 일정의 시작일·종료일 입력 대체 수단을 함께 둔다. Android Chrome과 iOS Safari 실기기 결과는 아직 확인 필요다.

## 보안

Preview에는 가짜 공사명과 날짜만 사용한다. 외부 전송, 위치·파일·카메라 권한, 개인정보 입력은 필요하지 않다. 향후 서버 저장을 붙이면 수정 권한 확인, 입력 날짜 검증, 변경 기록과 동시 수정 충돌 처리가 별도 필요하다.

## 저장

현재 프로젝트는 브라우저 저장소나 서버를 사용하지 않는다. Preview도 메모리에서만 변경하고 새로고침하면 초기 가짜 일정으로 돌아가게 한다. 실제 영구 저장 방식은 사용자 승인 후 별도 범위로 결정한다. FullCalendar의 종료일은 배타적이므로, 사용자에게 보이는 마지막 날짜와 저장 값 사이의 하루 차이를 변환해야 한다.

## Preview

기존 제품 파일을 변경하지 않는 별도 Preview에서 다음 한 흐름만 확인한다: 공사 막대 선택 → 왼쪽 끝을 다음 날로 이동 → 오른쪽 끝을 이전 날로 이동 → 표시 날짜 확인 → 새로고침 후 초기값 복원. 390px, 430px, 데스크톱에서 콘솔 오류와 날짜 경계도 함께 확인한다.
