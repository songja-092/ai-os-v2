# 쉬운 요약

## 요청

“공사 일정을 달력에 기간 막대로 표시하고 터치로 시작일과 종료일을 변경하게 해줘.”

## 가능 여부

가능합니다. 현재 사이트에는 이 기능이 없지만, 달력 막대와 휴대전화 터치 변경을 공식 지원하는 부품이 있습니다. 아직 실제 화면을 만들거나 휴대전화에서 시험한 단계는 아닙니다.

## 추천 방식

무료로 사용할 수 있는 FullCalendar의 일반 월 달력을 추천합니다. 공사 기간을 색상 막대로 보여 주고, 막대를 길게 누른 뒤 왼쪽 끝은 시작일, 오른쪽 끝은 종료일로 움직이게 합니다. 유료 공정표나 새 웹 기술로 사이트 전체를 바꿀 필요는 없습니다.

## 포함

- 한 달 달력
- 공사 기간을 나타내는 색상 막대
- 터치 또는 마우스로 시작일·종료일 변경
- 잘못된 날짜 변경 되돌리기
- 터치가 어려울 때 날짜를 직접 입력하는 보조 방법

## 제외

로그인, 여러 사람의 동시 편집, 인터넷 저장, 알림, 엑셀·PDF 출력, 복잡한 간트차트, 실제 사이트 통합과 배포는 이번 작은 시험 화면에 포함하지 않습니다.

## 위험

휴대전화에서는 날짜 칸이 좁아 막대 끝을 잡기 어려울 수 있고, 화면 스크롤과 길게 누르기가 겹칠 수 있습니다. 또한 달력 부품의 내부 종료일 계산 방식이 사람에게 보이는 날짜와 하루 다르므로 변환을 정확히 해야 합니다. 실제 Android와 iPhone 동작은 아직 확인 필요입니다.

## 다음 작업
