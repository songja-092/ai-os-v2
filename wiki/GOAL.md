# Goal

AI OS V2는 코딩을 전혀 모르는 사용자가 자연어로 원하는 소프트웨어를 설명하고, AI의 조사·기획·설계 결과를 눈으로 확인하고 선택하면서 실제로 작동하는 소프트웨어까지 완성할 수 있도록 돕는 개발 환경을 목표로 합니다.

사용자는 기술적인 코딩 작업보다 원하는 결과의 설명, 선택, 수정 요청과 최종 승인에 집중합니다. AI는 검증된 Skill, GitHub 오픈소스, 기존 자산과 성공 사례를 먼저 조사하고 재사용하며, 필요한 경우에만 최소한으로 직접 구현합니다.

아이디어·계획·구현·검증 상태를 명확히 구분하여 아직 구현되지 않은 것을 구현된 것처럼 표현하지 않습니다. 개발 과정과 확정된 결정은 Wiki와 GitHub에 지속적으로 보존하여 ChatGPT, Codex, Antigravity 등 작업 AI가 같은 프로젝트 기억을 공유할 수 있도록 합니다.
